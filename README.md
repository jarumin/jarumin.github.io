# Abdulhamid Modibbo — Portfolio

Personal portfolio website for Abdulhamid Modibbo, highlighting MEAL, Monitoring & Evaluation, programme management, data analytics, and dashboard projects.

## Publish with GitHub Pages

1. Create a repository named `jarumin.github.io`.
2. Upload the **contents of this folder** to the repository root (not the containing folder itself).
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Your site will be available at `https://jarumin.github.io/` after GitHub Pages finishes deploying.

The `.nojekyll` file is included so GitHub Pages serves the static site directly.
